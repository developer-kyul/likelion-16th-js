# 01 자바스크립트란?
자바스크립트는 ‘웹페이지에 생동감을 불어넣기 위해’ 만들어진 프로그래밍 언어입니다.

### 엔진 작동방식
1. 파싱 : 엔진이 스크립트를 읽는다.
2. 컴파일: 스크립트 > 기계어 변환
3. 기계어로 전환된 언어 실행

### 할 수 있는 일
- 페이지에 HTML을 추가하거나 기존HTMC,스타일 수정 가능  
- 마우스나 키보드 조작에 반응 가능  
- 네트워크를 통한 원격 서버에 요청 및 파일 업,다운로드
쿠키를 가져오거나 설정.  
- 클라이언트측에서 데이터 저장( LocalStorage )

### 할 수 없는 일
- 디스크에 저장된 임의의 파일 읽고 쓰기,복사 제약  
- 카메라 마이크는 사용자에게 명시적 허가 받아야함
- 내 탭과 창에대한 서로의 정보를 알 수 없음
- 타사이트 혹은 도메인에서 데이터 받기 불가

### 강점 
- HTML/CSS와 완전히 통합할 수 있음
- 간단한 일은 간단하게 처리할 수 있게 해줌
- 모든 주요 브라우저에서 지원하고, 기본 언어로 사용됨

# 2-3 엄격모드

```
"use strict";
```
- "use strict"는 스크립트 최상단에 있어야함. 그렇지 않으면 엄격 모드가 활성화되지 않을 수도 있음
- 자바스크립트 엔진을 이전 방식으로 되돌리는 "no use strict"같은 지시자는 존재하지 않습니다.
일단 엄격 모드가 적용되면 돌이킬 방법은 없습니다.

# 2-4 변수와 상수
### 변수
```
let // 최신
var // 예전

//선언 방법
let message = 'Hello!';
```

### 변수의 명명 규칙
- 변수명에는 오직 문자와 숫자, 그리고 기호 $와 _만 들어갈 수 있습니다.
- 첫 글자는 숫자가 될 수 없습니다.
- 카멜 표기법(camelCase) 흔하게 사용 [예]myVeryLongName
- 대소문자 구별
- 예약어는 사용할 수 없음

### 상수 
```
const myBirthday = '18.04.1982';
```
- 상수는 재할당할 수 없으므로 상수를 변경하려고 하면 에러가 발생합니다.
- 대문자 상수  
   - 기억하기 힘든 값을 변수에 할당해 별칭으로 사용하는 것은 널리 사용되는 관습입니다.
   - 이런 상수는 대문자와 밑줄로 구성된 이름으로 명명합니다.

```
const COLOR_RED = "#F00";
const COLOR_GREEN = "#0F0";
const COLOR_BLUE = "#00F";
const COLOR_ORANGE = "#FF7F00";

// 색상을 고르고 싶을 때 별칭을 사용할 수 있게 되었습니다.
let color = COLOR_ORANGE;
alert(color); // #FF7F00
```

# 2-5 자료형
- ‘동적 타입(dynamically typed)’ 언어

### 원시 자료형(Primitive, 값 자체) — 7개

| 자료형           | 대표 값                            | 의미                      |
| ------------- | ------------------------------- | ----------------------- |
| **number**    | `3`, `-1.07`, `NaN`, `Infinity` | 숫자 / 수학 연산 가능           |
| **bigint**    | `123n`                          | 아주 큰 정수 표현              |
| **string**    | `"hi"`, `'hi'`, `` `hi` ``      | 글자·문장 / 텍스트             |
| **boolean**   | `true`, `false`                 | Yes/No 판단               |
| **null**      | `null`                          | 값이 “없다 / 비어있다 / 아직 모른다” |
| **undefined** | `undefined`                     | 변수 선언만 하고 값 없음          |
| **symbol**    | `Symbol("id")`                  | 객체의 고유 식별자              |


### 참조 자료형 — 1개
| 자료형        | 대표 값                       | 의미                   |
| ---------- | -------------------------- | -------------------- |
| **object** | `{}`, `[]`, `function(){}` | 여러 값을 묶음 / 복잡한 구조 표현 |
