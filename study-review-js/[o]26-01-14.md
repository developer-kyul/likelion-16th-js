# 🌐 브라우저 작동 원리와 스크립트 실행 최적화

![alt text](image-3.png)

## 1. DTD (Document Type Definition)

- 정의: 브라우저에게 "이 문서는 어떤 HTML 버전으로 작성되었는지" 알려주는 선언입니다.

- 표준 모드(Standards Mode): <!DOCTYPE html> 선언을 통해 브라우저가 최신 HTML/CSS 사양에 맞게 화면을 렌더링하도록 합니다.

- 중요성: 이 선언이 없으면 브라우저가 **'쿼크 모드(Quirks Mode)'**로 동작하여, 오래된 브라우저처럼 제멋대로 렌더링될 수 있습니다.

## 2. 브라우저 파싱과 스크립트의 관계

- ⚠️ null이 발생하는 원인:  
  동기적 파싱
  브라우저는 HTML을 위에서 아래로 한 줄씩 읽습니다(동기적 파싱). 만약 <head> 안에서 DOM 요소를 찾는 JavaScript가 실행된다면, 아직 해당 태그를 읽기 전이므로 브라우저는 요소를 찾지 못하고 null을 반환합니다.

🛠️ 해결책의 진화
전통적인 최적화 (Legacy):

```jsx
<script> 태그를 </body> 바로 위에 배치합니다. HTML 파싱이 거의 끝난 시점에 스크립트를 실행하므로 에러를 방지할 수 있습니다.

현대적인 해결책 (defer):
<script src="..." defer>
```

- 작동 방식: HTML 파싱과 동시에 스크립트를 다운로드하고, 파싱이 완전히 끝난 뒤에 실행합니다.

- 장점: 파싱 중단이 없어 로딩 속도가 빠르고, DOM 조작 시 null 걱정이 없습니다.

## 3. 작동 구조 및 이벤트

🏗️ HTML Parser vs JavaScript Engine

- HTML Parser: HTML 텍스트를 읽어 DOM 트리를 건설합니다.
- JavaScript Engine: JS 코드를 해석하고 실행합니다.

```
파서가 <script>를 만나면 엔진에게 제어권을 넘기고, 엔진의 작업이 끝날 때까지 파서는 대기(Blocking)합니다.
```

📅 DOMContentLoaded 이벤트

- 시점: HTML 파싱이 완료되어 DOM 트리가 완성된 순간 발생합니다.
- 특징: 이미지나 스타일시트 로딩을 기다리지 않고 구조만 완성되면 바로 실행되므로, JS 조작을 시작하기 가장 좋은 타이밍입니다.

## 4. 내부 요소 집합 가져오기: NodeList

특정 요소 안에 포함된 여러 개의 자식 요소들을 한꺼번에 가져올 때 사용합니다.

🛠️ querySelectorAll()  
반환값: 조건에 맞는 모든 요소를 담은 NodeList를 반환합니다.

특징: 배열과 비슷해 보이지만 '유사 배열'입니다. 다행히 현대 브라우저에서는 .forEach() 메서드를 지원합니다.

```jsx
// 1. 특정 영역 내의 모든 리스트 아이템 가져오기
const characterList = document.querySelector("#exorcist-characters");
const characters = characterList.querySelectorAll(".character"); // NodeList 반환

// 2. NodeList 순회하며 조작하기
characters.forEach((item, index) => {
  console.log(`${index + 1}번째 캐릭터: ${item.textContent}`);
  item.style.color = "blue";
});
```

# DOM 요소 선택

ℹ️ 참고 사이트

- [MDN Web Docs (Mozilla): document.getElementById() - 실질적인 표준 가이드](https://developer.mozilla.org/ko/docs/Web/API/Document/getElementById)

- [WHATWG DOM Living Stand ard: getElementById 인터페이스 정의](https://dom.spec.whatwg.org/)

## 요소 선택 방법

| 구분 | 메서드                   | 특징                           |
| ---- | ------------------------ | ------------------------------ |
| 단수 | querySelector()          | CSS 선택자로 첫 번째 요소 반환 |
| 단수 | getElementById()         | ID 기반 접근, 가장 빠름        |
| 복수 | querySelectorAll()       | NodeList 반환                  |
| 복수 | getElementsByName()      | name 속성 기준                 |
| 복수 | getElementsByClassName() | HTMLCollection 반환            |
| 복수 | getElementsByTagName()   | 태그 기준 검색                 |

## 🚀 성능 최적화: 범위 좁히기 (Chaining)

- 복잡한 CSS 선택자(예: document.querySelector('.a .b .c'))는 성능 저하를 일으킬 수 있습니다.
- 변수를 활용해 범위를 한정하는 방식을 권장합니다.

```jsx
// ❌ 권장 안 함: 복잡한 선택자
const target = document.querySelector(".container .list .item");

// ✅ 권장: 단계별 범위 탐색 (성능 향상 및 코드 가독성)
const container = document.querySelector(".container");
const item = container.querySelector(".item");
```

# 요소찾기

```jsx
// 초기화
let masterChoi = null;
const exorcistCharacters = document.querySelector("#exorcist-characters");

// 1. 태그 이름으로 찾기
masterChoi = exorcistCharacters.getElementsByTagName("li").item(1);

// 2. 선택자(nth-child)로 찾기
masterChoi = exorcistCharacters.querySelector("li:nth-child(2)");

// 3. 클래스 이름으로 찾기
masterChoi = exorcistCharacters.getElementsByClassName("character").item(1);

// 4. 속성 이름과 값으로 찾기
masterChoi = exorcistCharacters.querySelector('[data-type="master"]');

console.log(masterChoi);
```

# 🎨 classList를 이용한 클래스 제어

| 메서드            | 설명        | 반환값  |
| ----------------- | ----------- | ------- |
| add(...tokens)    | 클래스 추가 | 없음    |
| remove(...tokens) | 클래스 제거 | 없음    |
| replace(old, new) | 클래스 교체 | boolean |

```jsx
element.classList.add(...tokens);
element.classList.remove(...tokens);
element.classList.replace(oldToken, newToken);
```

`classList` 객체는 요소의 클래스를 **추가, 삭제, 교체**하는 등  
클래스 목록을 동적으로 조작할 때 사용합니다.  
문자열 기반 `className`보다 **안전하고 편리한 현대적인 방식**입니다.

---

## 1. 클래스 추가 및 삭제 (add, remove)

여러 개의 클래스를 **쉼표(,)** 로 구분하여 한꺼번에 처리할 수 있습니다.

### ✅ 클래스 추가 (add)

지정한 클래스 값을 추가합니다.

```js
const example = document.querySelector(".example");

example.classList.add("good");              // 단일 추가
example.classList.add("good", "bad");       // 다중 추가
❌ 클래스 삭제 (remove)
지정한 클래스 값을 제거합니다.

js
코드 복사
example.classList.remove("bad");            // 단일 삭제
example.classList.remove("good", "bad");    // 다중 삭제
```

💡 void의 의미

- add와 remove 메서드에 커서를 올리면 void라고 표시됩니다.
- void란 반환값이 없다는 의미
- 아래처럼 변수에 담아도 값은 undefined

```jsx
const result = example.classList.add("good");
console.log(result); // undefined
```

➡️ 따라서 성공 여부를 판단하는 용도로는 사용하지 않습니다.

## 2. 클래스 교체 (replace)

기존 클래스를 새로운 클래스로 바꿀 때 사용합니다.

📌 문법

```jsx
element.classList.replace("기존클래스", "새클래스");
```

📌 특징
replace()는 void가 아님

- boolean 값(true / false)을 반환

✅ 활용 예시 (조건문과 함께 사용)

```jsx
// 'is-failed'를 찾아 'is-success'로 교체
const result = messageElement.classList.replace("is-failed", "is-success");

if (result) {
  // 기존 클래스가 있어서 교체에 성공한 경우
  console.log("성공적으로 변경되었습니다!");
} else {
  // 바꾸려는 기존 클래스가 없는 경우
  console.log("변경할 클래스를 찾지 못했습니다.");
}
```

- true → 기존 클래스 존재, 교체 성공
- false → 기존 클래스 없음, 교체 실패

➡️ 조건 처리에 매우 유용

## 3. 요약 및 비교

| 메서드       | 역할        | 반환값 (Return) | 특징                        |
| ------------ | ----------- | --------------- | --------------------------- |
| `.add()`     | 클래스 추가 | void            | 여러 개 동시 추가 가능      |
| `.remove()`  | 클래스 삭제 | void            | 여러 개 동시 삭제 가능      |
| `.replace()` | 클래스 교체 | boolean         | 성공 시 true, 실패 시 false |
| `.toggle()`  | 클래스 반전 | boolean         | 없으면 추가, 있으면 삭제    |
