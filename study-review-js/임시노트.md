CI란(Continuos Integration)?

코드를 지속적으로 수정하고 업데이트를 하는 작업을 의미합니다. 예를들어 웹사이트를 한번만 만들고 거기에서 끝나는게 아니라 새로운 내용이나 버그를 수정하는 것 또는 더 좋은 기술을 적용하는 것을 의미합니다. 예를들어 깃허브에 코드 수정 후에 푸시하는 작업까지 보면 될 것같습니다.

CD(Continuos Deploy / Continuos Delevary) 란?

코드를 올렸다면 웹 페이지를 올려야겠죠 이때 git action을 통해 최초로 올릴 때 직접 올리는것 그리고 깃 푸시를 했을 때 웹 페이지에 자동으로 업데이트되는데 이러한 작업을 CD라고 합니다.
