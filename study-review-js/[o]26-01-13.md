# 스택과 힙

- JavaScript는 데이터의 특성에 따라 두 가지 메모리 공간을 나누어 사용

| **구분**                    | **스택 (Stack)**      | **힙 (Heap)**      |
| --------------------------- | --------------------- | ------------------ |
| **저장 데이터**             | 기본 타입 (Primitive) |
| 숫자, 문자, 불리언, Null 등 | 참조 타입 (Reference) |
| 객체, 배열, 함수 등         |
| **특징**                    | 크기가 작고 고정적    | 크기가 크고 동적임 |
| **접근 속도**               | 빠름                  | 상대적으로 느림    |
| **저장 방식**               | 값 자체를 저장        | 주소(참조)를 저장  |

# 데이터 타입별 저장 방식

## 1. 기본 타입 (primitive type) 객체 저장 방식 (stack)

기본 타입은 스택에 직접 값을 저장합니다. 값을 복사하면 완전히 독립된 새로운 메모지가 하나 더 생기는 것과 같습니다.

- 상황: 상영이가 메모지에 "사과"라고 쓰고, 해인이가 그걸 보고 자기 메모지에 "사과"라고 베낍니다.

- 결과: 해인이가 자기 메모지를 "바나나"로 고쳐도, 상영이의 메모지는 여전히 "사과"입니다.

```jsx
let name = '네무'
let new_name = name // '네무'라는 값이 새로운 메모리 공간에 복사됨

new_name = '야무' // new_name의 공간에만 새로운 값 '야무'가 저장됨

[스택 (Stack)]
┌──────────────────┐
│ name: '네무'      │ ← 원본 값
├──────────────────┤
│ new_name: '야무' │ ← 복사된 값 (독립적으로 변경됨)
└──────────────────┘
```

## 2. reference type 객체 저장 방식 (heap)

객체는 힙에 저장되며, 변수(스택)는 그 객체가 있는 **주소**만 들고 있습니다.

- 상황: 준우의 메모지에 "서울시 길음로 33번지"가 적혀 있고, 수아가 그 주소를 똑같이 적습니다.

- 결과: 수아가 그 주소로 찾아가 현관문을 파란색으로 칠하면, 준우가 나중에 그 주소로 찾아갔을 때도 문은 파란색입니다. (같은 집을 공유하기 때문)

```jsx
const person = { name: '성준일', age: 57 }
const new_person = person // 주소(참조) 복사

new_person.age = 21 // 주소를 타고 들어가 실제 힙 공간의 데이터를 수정
console.log(person.age) // 21 (동일한 객체를 보고 있으므로 값이 함께 변경됨)

[스택 (Stack)]                      [힙 (Heap)]
(주소/신분증을 담는 상자들)              (실제 데이터가 사는 공유 저택)
┌──────────────────────┐           ┌───────────────────────────┐
│ person: 주소A         │ ───────→  │ { name: '성준일', age: 21 } │
├──────────────────────┤        ↗  └───────────────────────────┘
│ new_person: 주소A     │ ───────┘         (실제 데이터 저장소)
└──────────────────────┘                  [주소A] 메모리 영역
           ↑
 둘 다 동일한 '주소A'를 가짐
     (독립된 주소 상자)
```

# BOM & DOM

- BOM : 브라우저 전체 시스템 관리 (관리 사무소) - window 객체
- DOM : 웹 문서 내부의 내용 관리 (집 안 가구) - document 객체

### 각 환경의 전역 객체

- Node.js - global (JavaScript 언어 + Node.js 환경에 내장된 다양한 기능(API))
- Browser - window (JavaScript 언어 + Browser 환경에 내장된 다양한 기능(API))

# BOM (Browser Object Model)

- BOM은 브라우저가 제공하는 JavaScript 객체 집합을 의미합니다.
- 브라우저가 제공하는 JavaScript 객체 중, 가장 근본(Root)가 되는 객체는 Window 객체입니다.

### BOM - Window 객체 탐색

```jsx
// 1. 최상위(root) 객체인 window를 콘솔에 출력하세요.
console.log(window) // Window { navigator, location }

// 2. window 객체의 navigator 속성을 통해 브라우저 정보를 출력하세요. (점 표기법 사용)

// 객체의 속성에 접근
// - 점(.) 표기법
 console.log(window.navigator.userAgent)
  Navigator { userAgent }
// - 대괄호([]) 표기법
console.log(window['navigator']['userAgent'])

// 3. 위와 동일한 정보를 window를 생략하고 출력해 보세요. (전역 객체의 특징)
console.log(navigator, typeof navigator) // 'object'
console.log(navigator.userAgent, typeof navigator.userAgent) // 'string'


```

### BOM - 브라우저 제어 (확인 및 이동)

```jsx
// 1. 사용자에게 '유튜브 페이지로 이동할까요?'라고 묻는
//    확인창(confirm)을 띄우고 결과를 변수 `userConfirm`에 담으세요.
const moveToYoutube = window.confirm("유튜브 페이지로 이동할까요?");
// console.log(moveToYoutube) // Boolean

// 2. 조건문을 작성하세요.
//    - [참일 때]: '네. 유튜브 페이지로 이동할게요!' 경고창(alert)을 띄우고,
`window.location.href`를 'https://www.youtube.com'으로 변경하세요.
if (moveToYoutube) {
  window.alert("네. 유튜브 페이지로 이동할게요!");
  window.location.href = "https://www.youtube.com";
}
//    - [거짓일 때]: '네. 유튜브 페이지로 이동을 취소할게요!' 경고창을 띄우세요.
else {
  window.alert("네. 유튜브 페이지로 이동을 취소할게요!");
}
```

### DOM - Document 객체와 트리 구조

### DOM - 문서 정보 접근 및 수정

```jsx
// 1. 문서 정보 읽기
console.log("현재 제목:", document.title);
console.log("현재 주소:", document.URL);

// 2. 문서 정보 수정 (브라우저 탭 제목 변경)
document.title = "반갑습니다!";

// 3. BOM과 DOM의 연결 확인
console.log(document === window.document); // true
```

# 비교

| 구분          | BOM (Browser Object Model)                      | DOM (Document Object Model)           |
| ------------- | ----------------------------------------------- | ------------------------------------- |
| 의미          | 브라우저가 제공하는 JavaScript 객체 집합        | HTML 문서를 해석하여 구성한 객체 구조 |
| **제어 대상** | 브라우저 창 전체 (뒤로가기, 주소창, 팝업 등)    | 브라우저 안의 HTML 문서 내용          |
| 핵심 객체     | `window`, `globalThis`                          | `document`                            |
| 주요 역할     | 브라우저 창 및 환경 관리 (팝업, URL, 타이머 등) | HTML 문서 구조를 표현하고 조작        |
| 접근 방법     | `window` 또는 `window.속성`                     | `document`, `window.document`         |
| **표준 여부** | 브라우저마다 조금씩 다름 (비표준 포함)          | W3C 표준 (모든 브라우저 공통 규칙)    |

# DOM 요소선택

## 1. 과거방식

```jsx
const element = document.querySelector(selector);

document.querySelector("#id");
document.querySelector(".class");
document.querySelector("tag-name");
document.querySelector('[aria-hidden="true"]');
```

## 2. 현대 방식

```jsx
document.querySelector("#chapter");
// <article id="chapter">

document.querySelector(".sr-only");
// <h2 class="sr-only">

document.querySelector('[title*="Model"]');
// <abbr title="Document Object Model">
```

선택하고자 하는 요소엔  
class : " .클래스명"  
태그 : " 태그"  
id : "#id명"  
속성 : '[aria-hidden="true"]'
