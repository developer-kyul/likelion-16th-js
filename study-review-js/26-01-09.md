실행 컨텍스트(Execution Context)
정의: 코드가 실행되는 "작업대"=환경(Environment)

JavaScript 엔진이 코드를 실행하기 위해 필요한 모든 환경 정보를 모아놓은 객체입니다.
핵심 역할: 변수, 함수 선언 등을 저장하고 this를 결정하며 코드를 순차적으로 실행합니다.

실행 컨텍스트의 종류
전역 컨텍스트
생성 시점: 파일 로드 시(딱 한 번)
특징:전역 객체 생성, this 바인딩
생명 주기:프로그램 종료 시 소멸

지역 컨텍스트
생성 시점: 함수가 호출될 때마다
특징: 각 함수만의 독립적인 환경 제공
생명 주기:함수 종료(return) 시 소멸, 메모리에서 삭제

실행 컨텍스트의 구조


[메모리 영역] 환경 레코드 (Environment Record)


재료 창고: 현재 스코프 내의 변수명과 함수 선언을 Key:Value 형태로 저장합니다.
호이스팅: 코드 실행 전 이 창고를 채우는 과정 때문에 발생합니다.

🧵 [실행 영역] 실행 스레드 (Thread of Execution)


조리대: 코드를 한 줄씩 읽으며 실제로 실행하는 흐름입니다.
싱글 스레드: JavaScript는 한 번에 하나의 실(Thread)로만 바느질하듯 처리하므로, 한 작업이 끝나야 다음으로 넘어갑니다. (동기적 특성)

실행 컨텍스트 작동 원리
실행 컨텍스트의 2단계 구조
자바스크립트 엔진은 코드를 읽을 때 [환경 레코드 생성] → [코드 실행]의 순서를 따릅니다.

1단계-생성 단계 (Creation Phase) - 호이스팅 발생
핵심 동작: 선언문만 훑어서 메모리에 등록,let, const 변수 등록

2단계-실행 단계 (Execution Phase) - TDZ 해제 및 값 업데이트
핵심 동작: 코드를 한 줄씩 읽으며 할당 및 실행


JavaScript 실행 환경의 3요소


실행 컨텍스트 (Execution Context)
- 작업대: 코드가 실행되는 환경 (전역/함수).
- 생명 주기: 함수 호출 시 생성 ➔ 실행 ➔ 종료 시 삭제.
환경 레코드 (Environment Record)
- 재료 창고: 컨텍스트 내부의 변수와 함수를 Key:Value로 저장.
- 호이스팅: 생성 단계에서 이 창고를 미리 채우는 현상.
스코프 체인 (Scope Chain)
- 연결 고리: 현재 창고에 재료가 없으면 상위 창고로 찾아 올라가는 경로.
- 방향성: 안쪽 ➔ 바깥쪽으로만 탐색 가능 (정보 은닉의 기초).

객체는 키(key)-값(value) 쌍을 포함하는 데이터
중괄호( { } ) 안에 키-값 쌍을 작성하여 객체를 생성
여러 키-값 쌍을 생성하려면 다음과 같이 각 쌍을 쉼표( , )로 구분

객체에 포함 가능한 값
모든 JavaScript 값 (문자열, 숫자, 불린, 배열, 함수, 객체 등)

객체 속성 값 읽기-객체의 키(key) = 속성(Property)
점 표기법 : object.key
대괄호 표기법 : object['key']

---> 대괄호 표기법 사용하는 경우
키에 공백/특수문자가 있을 때
키를 변수로 사용할 때

속성 값 쓰기
object.key = 값 또는 object['key'] = 값

속성 삭제 방법
delete object.key 또는 delete object['key']

함수도 객체
함수에 속성 추가 가능 (함수명.속성 = 값)

메서드(Method)
객체 속성으로 포함된 함수 (object.method())

함수는 일급 객체
일급 객체 → 함수를 인자로 넘기거나, 변수에 대입 가능한 연산 지원
일급 함수 → 함수를 객체와 동일하게 사용 가능 (함수 = 객체 = 값)
