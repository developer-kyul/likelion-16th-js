# Undefined

> undefined는 "값이 없음을 나타내는 값"

- JavaScript 엔진이 자동으로 할당

[Undefined 적용 사례]

1. 변수 선언만 한 경우
2. 함수 반환 값을 명시하지 않은 경우
3. 객체의 존재하지 않는 속성에 접근할 경우
4. 배열의 존재하지 않는 요소의 인덱스로 접근할 경우
5. 함수의 매개변수에 아무런 값이 전달되지 않은 경우

```jsx
[예시];
// 1. 변수 선언만 한 경우
let data;
console.log(data); // undefined

//2. 함수 반환 값을 명시하지 않은 경우
function fn() {}
console.log(fn()); // undefined

//3. 객체의 존재하지 않는 속성에 접근할 경우
const user = {
  name: "이준",
  age: 20,
};

console.log(user.name); // '이준'
console.log(user.email); // ⚠️ undefined (존재하지 않는 속성)

//4. 배열의 존재하지 않는 요소의 인덱스로 접근할 경우
const fruits = ["천혜향", "애플망고"];

console.log(fruits[0]); // '천혜향'
console.log(fruits[1]); // '애플망고'
console.log(fruits[2]); // ⚠️ undefined (존재하지 않는 인덱스)

// 5. 함수의 매개변수에 아무런 값이 전달되지 않은 경우
function greet(name, age) {
  console.log(name); // '현정'
  console.log(age); // ⚠️ undefined (전달되지 않음)
}

greet("현정");
```

# Null

> null은 "빈 상태(empty state)"

- 개발자가 명시적으로 "지금 이 변수는 비어 있어!"라고 선언할 때 null

[Null 적용 사례]

1. 초기값 설정할 경우
2. 초기화 설정할 경우
3. 데이터베이스 값 없음 표현할 경우
4. 함수 반환 값이 없음을 명시적으로 표현할 경우

```jsx
//1. 초기값 설정할 경우
// 사용자 정보가 아직 로드되지 않음을 명시
let currentUser = null;

// 로그인 후
currentUser = {
  name: "jee",
  email: "jee@example.com",
};

//2. 초기화 설정할 경우
// 로그아웃
currentUser = null;

//3. 데이터베이스 값 없음 표현할 경우
const user = {
  name: "jee",
  age: 21,
  profileImage: null, // 프로필 이미지가 없음
  bio: null, // 자기소개가 없음
};

//4. 함수 반환 값이 없음을 명시적으로 표현할 경우
function findUser(id) {
  const users = [
    { id: 1, name: "재민" },
    { id: 2, name: "상우" },
  ];

  const user = users.find((u) => u.id === id);

  // 사용자를 찾지 못하면 null 반환
  return user || null;
}

console.log(findUser(1)); // { id: 1, name: '재민' }
console.log(findUser(99)); // null ⚠️ 사용자를 찾을 수 없음
```

# Undefined vs Null

# Null vs Undefined

`null`과 `undefined`는 둘 다 "값이 없음"을 나타내지만, 사용 목적이 다릅니다.

| 구분          | Undefined                                     | Null                                         |
| ------------- | --------------------------------------------- | -------------------------------------------- |
| **정의**      | 값이 "**정의되지 않음**"을 나타내는 값        | 값이 "**비어있음**"을 명시적으로 나타내는 값 |
| **의미**      | "값이 아직 정해지지 않았어" (의도 ❌)         | "여기는 확실히 비어 있어" (의도 ✅)          |
| **할당 주체** | JavaScript 엔진이 자동으로 할당               | 개발자가 명시적으로 할당                     |
| **발생 상황** | - 변수를 선언했지만 값을 할당하지 않은 경우   | - 의도적으로 "값이 비어있다"는 의미 설정     |
|               | - 명시적으로 값을 반환하지 않은 함수의 반환값 | - 개발자가 명시적으로 할당                   |
|               | - 존재하지 않는 속성에 접근                   |                                              |
|               | - 전달되지 않은 함수 매개변수                 |                                              |

## Undefined 사용

- ✅ 변수를 선언만 하고 값을 나중에 할당할 때
- ✅ 함수에서 값을 반환하지 않을 때
- ❌ 명시적으로 `undefined`를 할당하지 마세요

## Null 사용

- ✅ 의도적으로 "값이 없음"을 표현할 때
- ✅ 객체나 값을 초기화할 때
- ✅ 나중에 값이 할당될 것을 명시할 때

## Null vs Undefined - 동치 비교 (===)

```jsx
console.log(null === undefined); // false
console.log(null == undefined); // true
```

⚠️ 비교를 수행할 땐 항상 ===, !== 연산자를 사용

# 논리 연산자와 표현식

**논리곱(&&, AND)** 연산자는 첫번째 거짓 같은 값(Falsy)를 찾고, 만약 모두 참 같은 값(Truthy)인 경우 맨 마지막 값을 반환

**논리합(||, OR)** 연산자는 첫번째 참 같은 값(Truthy)를 찾고, 만약 모두 거짓 같은 값(Falsy)인 경우 맨 마지막 값을 반환

&&, || 조건처리

```jsx
{
  // &&, || 조건 처리

  // 표현식(Expression)
  // - 계산 후, 값을 구하는 과정(평가)

  // 표현식에서의 논리곱(&&, AND) 연산자
  // - 첫 번째 거짓 같은 값(Falsy)를 찾는 연산자
  let result1 = 1 && {} && "" && -1 && 10n && [0, 1, 2];
  console.log(result1);

  // 표현식에서의 논리합(||, OR) 연산자
  // - 첫 번째 참 같은 값(Truthy)를 찾는 연산자
  let result2 = "false" || "" || null || undefined || Symbol();
  console.log(result2);
}
```

# 조건문

- if … else 문 : 조건에 따라 다른 코드를 실행하는 제어 흐름 문입니다.
- Falsey 값 : false, undefined, null, 0, "", NaN (이 외는 모두 Truthy)
- 느슨한 비교(==) : 타입을 자동 변환한 후 비교합니다.
- 엄격한 비교(===) : 타입과 값 모두 일치해야 true를 반환합니다.

# if … else 문 - 기본 구조

```jsx
if (조건) {
  console.log("조건이 참인 경우 블록 실행");
} else {
  console.log("조건이 거짓인 경우 블록 실행");
}
```

## 참, 거짓 평가

모든 조건은 표현식이므로 참(Truthy) 또는 거짓(Falsey)인지 평가합니다.  
JavaScript에서 값이 거짓(Falseey)로 평가되는 경우는 다음의 6가지 입니다.

1. `false`
2. `undefined`
3. `null`
4. `0`
5. `""` (빈 문자열)
6. `NaN` (Not a Number)

### 불리언 타입 변경

- JavaScript가 제공하는 Boolean() 함수를 사용하면 전달된 표현식을 불리언 타입으로 변경

```jsx
boolean(표현식);
```

### 자동 타입 변경

- 조건문 내부에서 평가되는 표현식은 자동으로 블리언(Boolean) 타입으로 변경

```jsx
if (10 - 8 - 4 + 2) {
  console.log("조건이 참입니다.");
} else {
  console.log("조건 계산 값이 0이므로 거짓(falsey)으로 평가됩니다.");
}
```

### 다양한 표현 방식

```jsx
// 기본 코드
if (value) {
  console.log("참");
} else {
  console.log("거짓");
}

// 한 줄로 작성
if (value) {
  console.log("참");
} else {
  console.log("거짓");
}

//중괄호 생략
if (value) console.log("참");
else console.log("거짓");
```

# 느슨한 비교가 부른 대참사

> ⚠️ **0원인 것과 데이터가 없는 것은 큰 차이*!***

> **숫자 `0`** : "잔액이 정확히 0원입니다"라는 **정상적인 정보** > **`null` 또는 `false`** : "데이터를 가져오는 데 실패했습니다."라는 **비정상적인 상태**

# 요약

| 구분                      | 내용                                                     |
| ------------------------- | -------------------------------------------------------- |
| **if … else 문**          | 조건에 따라 다른 코드를 실행하는 제어 흐름 문            |
| **Falsey 값**             | `false`, `undefined`, `null`, `0`, `""`, `NaN`           |
| **`Boolean()`**           | 값을 명시적으로 `true` 또는 `false`로 변환               |
| **크기 비교 연산자**      | `>`, `>=`, `<`, `<=`                                     |
| **동등 비교 연산자**      | `==` (느슨한 비교, 타입 변환 O)                          |
| **완전 동일 비교 연산자** | `===` (엄격한 비교, 타입 변환 X)                         |
| **다름 비교 연산자**      | `!=` (느슨한 비교), `!==` (엄격한 비교)                  |
| **느슨한 비교 특징**      | 타입 자동 변환 후 비교 (예: `'24' == 24` → `true`)       |
| **엄격한 비교 특징**      | 타입과 값 모두 일치해야 `true` (`'24' === 24` → `false`) |
| **else if 문**            | 여러 조건을 순차적으로 검사하는 방법                     |
