## text 및 HTML 변경

- textContent : 요소 안의 "텍스트만" 변경 (HTML 태그는 문자로 처리됨)
- innerHTML : 요소 "내부"의 HTML 구조를 포함해 변경
- outerHTML : 요소 "자기 자신 + 내부" 전체를 HTML로 교체

```jsx
요소.textContent = "텍스트";
요소.innerHTML = "HTML 문자열";
요소.outerHTML = "HTML 문자열";
```

## DOM에 요소 추가

### 요소 생성

createElement : 요소 생성
이때 생성된 요소는 메모리에만 존재하며, 아직 화면(DOM)에는 나타나지 않습니다.

```
document.createElement('태그명')
```

### 요소 추가

appendChild() : 마지막 자식 요소로 추가
insertBefore() : 대상 요소 앞에 요소 삽입

```jsx
부모.appendChild(자식);
부모.insertBefore(새요소, 기준요소);
```

## 다양한 추가 메서드

- .prepend() : 요소의 첫번째 자식 요소 뒤에 다른 요소(들) 삽입
- .append() : 요소의 마지막 자식 요소 뒤에 다른 요소(들) 삽입
- .before() : 요소 앞에 다른 요소(들) 삽입
- .after() : 요소 뒤에 다른 요소(들) 삽입
- .insertAdjacentElement() : 특정 위치에 요소 삽입
- .insertAdjacentHTML() : 특정 위치에 HTML 삽입
