텍스트 / HTML 조작

## text 및 HTML 변경

- textContent : 요소 안의 "텍스트만" 변경 (HTML 태그는 문자로 처리됨)
- innerHTML : 요소 "내부"의 HTML 구조를 포함해 변경
- outerHTML : 요소 "자기 자신 + 내부" 전체를 HTML로 교체

DOM에 요소 추가
