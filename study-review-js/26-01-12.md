# Undefined

> undefined는 "값이 없음을 나타내는 값"

- JavaScript 엔진이 자동으로 할당

[Undefined 적용 사례]

1. 변수 선언만 한 경우
2. 함수 반환 값을 명시하지 않은 경우
3. 객체의 존재하지 않는 속성에 접근할 경우
4. 배열의 존재하지 않는 요소의 인덱스로 접근할 경우
5. 함수의 매개변수에 아무런 값이 전달되지 않은 경우

# Null

> null은 "빈 상태(empty state)"

- 개발자가 명시적으로 "지금 이 변수는 비어 있어!"라고 선언할 때 null

[Null 적용 사례]

1. 초기값 설정할 경우
2. 초기화 설정할 경우
3. 데이터베이스 값 없음 표현할 경우
4. 함수 반환 값이 없음을 명시적으로 표현할 경우
