# Undefined

> undefined는 "값이 없음을 나타내는 값"

- JavaScript 엔진이 자동으로 할당

[Undefined 적용 사례]

1. 변수 선언만 한 경우
2. 함수 반환 값을 명시하지 않은 경우
3. 객체의 존재하지 않는 속성에 접근할 경우
4. 배열의 존재하지 않는 요소의 인덱스로 접근할 경우
5. 함수의 매개변수에 아무런 값이 전달되지 않은 경우

# Null

> null은 "빈 상태(empty state)"

- 개발자가 명시적으로 "지금 이 변수는 비어 있어!"라고 선언할 때 null

[Null 적용 사례]

1. 초기값 설정할 경우
2. 초기화 설정할 경우
3. 데이터베이스 값 없음 표현할 경우
4. 함수 반환 값이 없음을 명시적으로 표현할 경우

# 논리 연산자와 표현식

**논리곱(&&, AND)** 연산자는 첫번째 거짓 같은 값(Falsy)를 찾고, 만약 모두 참 같은 값(Truthy)인 경우 맨 마지막 값을 반환

**논리합(||, OR)** 연산자는 첫번째 참 같은 값(Truthy)를 찾고, 만약 모두 거짓 같은 값(Falsy)인 경우 맨 마지막 값을 반환

&&, || 조건처리

```jsx
{
  // &&, || 조건 처리

  // 표현식(Expression)
  // - 계산 후, 값을 구하는 과정(평가)

  // 표현식에서의 논리곱(&&, AND) 연산자
  // - 첫 번째 거짓 같은 값(Falsy)를 찾는 연산자
  let result1 = 1 && {} && "" && -1 && 10n && [0, 1, 2];
  console.log(result1);

  // 표현식에서의 논리합(||, OR) 연산자
  // - 첫 번째 참 같은 값(Truthy)를 찾는 연산자
  let result2 = "false" || "" || null || undefined || Symbol();
  console.log(result2);
}
```

# 조건문

- if … else 문 : 조건에 따라 다른 코드를 실행하는 제어 흐름 문입니다.
- Falsey 값 : false, undefined, null, 0, "", NaN (이 외는 모두 Truthy)
- 느슨한 비교(==) : 타입을 자동 변환한 후 비교합니다.
- 엄격한 비교(===) : 타입과 값 모두 일치해야 true를 반환합니다.

## if … else 문 - 기본 구조

```jsx
if (조건) {
  console.log("조건이 참인 경우 블록 실행");
} else {
  console.log("조건이 거짓인 경우 블록 실행");
}
```

## 참, 거짓 평가

모든 조건은 표현식이므로 참(Truthy) 또는 거짓(Falsey)인지 평가합니다.  
JavaScript에서 값이 거짓(Falseey)로 평가되는 경우는 다음의 6가지 입니다.

1. `false`
2. `undefined`
3. `null`
4. `0`
5. `""` (빈 문자열)
6. `NaN` (Not a Number)

### 불리언 타입 변경

### 자동 타입 변경

- 조건문 내부에서 평가되는 표현식은 자동으로 블리언(Boolean) 타입으로 변

```jsx
if (10 - 8 - 4 + 2) {
  console.log("조건이 참입니다.");
} else {
  console.log("조건 계산 값이 0이므로 거짓(falsey)으로 평가됩니다.");
}
```

#### 다양한 표현 방식

```jsx
// 기본 코드
if (value) {
  console.log("참");
} else {
  console.log("거짓");
}

// 한 줄로 작성
if (value) {
  console.log("참");
} else {
  console.log("거짓");
}

//중괄호 생략
if (value) console.log("참");
else console.log("거짓");
```
