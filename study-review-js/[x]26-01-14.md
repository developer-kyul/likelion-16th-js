# bun 개발환경 설정

CLI

```cli
bun add live-server -D (개발용 서버)
```

package.json

```jsx
{
  "scripts": {
    //"단축명령어": "패키지이름(명령어) --옵션1=값 --옵션2=값",
    "dev": "live-server --host=localhost --port=3000 --no-browser",
    "dev:bun": "bun learn.html"
  },
  "dependencies": {
    "live-server": "^1.2.2"
  }
}
```

npm 설정사이트 : https://www.npmjs.com/package/live-server
